# alu.v — 전체 줄별 해설

[분석 안내로 돌아가기](../README.ko.md) · [원본 파일](../../rtl/alu.v)

원본 물리적 줄 수: **169줄**. 아래 표는 빈 줄과 주석을 포함한 모든 줄을 다룬다. 여러 줄 표현식의 각 행은 앞뒤 행과 이어서 읽는다.

32비트 조합 ALU이다. 연산 결과와 함께 동등 비교 및 작다 비교를 항상 병렬로 계산한다. 세 시프트 회로는 가변 시프트 연산자 대신 0~31 각각의 고정 배선을 나열한다.

| opsel | 결과 | 관련 제어 |
|---|---|---|
| 000 | op1 + op2 또는 op1 - op2 | sub |
| 001 | 왼쪽 논리 시프트 | op2[4:0] |
| 010/011 | 비교 결과 0 또는 1 | unsigned |
| 100 | XOR | 없음 |
| 101 | 오른쪽 논리/산술 시프트 | arith |
| 110 | OR | 없음 |
| 111 | AND | 없음 |

signed 비교는 부호가 다르면 음수가 작고, 부호가 같으면 원래 32비트 unsigned 비교와 순서가 같다는 성질을 사용한다. 예: 0xffffffff와 1은 signed로 -1<1이지만 unsigned로 4294967295>1이다. 산술 결과는 32비트로 잘리므로 0xffffffff+1은 0이다.
